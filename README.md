# Gestão Contábil — demonstração

Uma proposta de aplicativo desktop para ajudar pequenos escritórios contábeis a organizar o acompanhamento de clientes, prazos e rotinas do dia a dia.

## A ideia

Reunir em um só lugar informações que costumam ficar espalhadas em planilhas e anotações. A proposta é facilitar a consulta de pendências, o acompanhamento de tarefas e a localização de documentos.

## O que a proposta contempla

- Visão geral de clientes e atividades pendentes.
- Acompanhamento de obrigações e prazos.
- Organização de documentos e informações de cobrança.
- Interface desktop pensada para uso simples no escritório.

## Sobre esta demonstração

Este repositório apresenta somente o conceito do projeto. Não inclui o código-fonte, planilhas, documentos, nomes ou outros dados de clientes. As funcionalidades descritas são uma visão geral da proposta e não constituem orientação contábil ou fiscal.
